# PrepPilot - B.Tech Placement & Career Operating System 🚀

PrepPilot is an AI-powered placement preparation and career operating system built specifically for B.Tech students from Year 1 to Year 4. It bridges the gap between college coursework and company hiring benchmarks through structured, semester-wise execution tracks.

---

## 🌟 Key Features

1. **Year-Adaptive Execution Roadmaps:** Semester-wise checklists tailored for Product (Tier-1), FinTech, and Specialist Service placement tracks.
2. **Zero-Loss Tier Switching (Delta Engine):** Switch placement tiers anytime without losing progress on core foundations (DSA, OOPs, DBMS).
3. **Adaptive AI Mock Interview Round:** Company-locked live interview simulator powered by Google Gemini with real-time Web Speech recognition and bar-raiser evaluation rubrics.
4. **AI ATS Resume Auditor:** Scans resume bullets for target company keyword density, STAR quantifiable metrics, and single-column parser compliance.
5. **Printable Company PYQ Archives:** Curated, verified 50-question placement banks for 2024–2025 hiring drives.
6. **Production Project Blueprints:** Step-by-step recruiter-grade project architectures with ready-to-use resume STAR bullets.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS, Lucide React, Web Speech API
- **AI Engine:** Google Gemini API (`gemini-2.5-flash`)
- **State & Storage:** Client-Side Edge Orchestration, Browser Persistent Storage (LocalStorage)
- **External Data:** Open-Source Community Question Feeds
